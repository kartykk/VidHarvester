VidHarvester **Video Link Harvester & Downloader** A practical, production-ready Python tool that: 1. Crawls any website (BFS) and discovers **all video links** (direct `.mp4`, HLS `.m3u8`, DASH, embeds, JavaScript-loaded sources, etc.). 2. Builds a clean, deduplicated list.
